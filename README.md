
# Getting Started

To use this project, download the code from this repository.

1. Download the project files.
2. Open your **Downloads** folder.
3. Open the downloaded project folder.
4. Locate the `index.html` file.
5. Double-click `index.html` to launch the website in your web browser.

No installation or additional software is required. Simply open the HTML file and the website will run locally on your computer.
